# Logos de réseau complémentaires

Pastilles 24×24 pour les réseaux que web3icons ne couvre pas. Chaque fichier
`<id-de-chaîne>.svg` est lu par `scripts/gen-chain-logos.mjs` quand web3icons
n'a rien pour ce réseau.

Règles : uniquement le logo **officiel** du réseau (jamais redessiné), même
format que web3icons (carré 24×24 plein, affiché en rond), vérifié à l'œil en
grand et en 32 px avant ajout.

| Réseau | Source | Récupéré |
|---|---|---|
| memecore | Symbole extrait du logo SVG officiel (memecore.com, via Brandfetch), sans le texte, sur fond blanc comme l'icône officielle | 2026-10-31 |

Les logos restent la propriété de leurs projets ; ils servent uniquement à
identifier le réseau dans le portefeuille.
